## 📌 Project Overview

This is a **modern eCommerce demo website** created to showcase a high-converting online store layout.
It is designed for brands selling **home essentials, beauty products, health & wellness items, and lifestyle products**.

The goal of this demo is to give a clear idea of:

* UI/UX design quality
* Conversion-focused layout
* Real-world eCommerce structure

---

## ✨ Key Features

* 🧭 Clean & modern navigation bar
* 🎯 High-converting hero section
* 🛒 Product cards with pricing & offers
* 🔥 Best sellers & trending products section
* 📦 Trust indicators (COD, Free Shipping, Returns)
* ⭐ Customer reviews & ratings system
* ❓ FAQ section for user clarity
* 📱 Fully responsive design (Mobile + Desktop)
* ⚡ Smooth animations & interactions

---

## 🎨 Design Highlights

* Premium typography (Plus Jakarta Sans & Fraunces)
* Soft color palette for better readability
* Micro-interactions for better user engagement
* Conversion-focused layout (inspired by real D2C brands)
